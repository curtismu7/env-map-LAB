# env-map-lab

Tool-tier standalone app (port 7805): "Where Everything Runs", a map of where a team's software runs (local Docker, Kubernetes namespaces, SaaS) as a ReactFlow diagram and a table, with a what-if computed from roles. Mock = the made-up `data/sample-snapshot.json`; Real = a snapshot file (`ENV_MAP_SNAPSHOT`) written by the owner-run read-only `scripts/collect.sh`, read-only, loopback only.

- Run: `./scripts/run.sh` (http://127.0.0.1:7805/) or `HOST_PORT=7805 docker compose up --build -d` (OrbStack, Mock only). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest against the real server in a child process; repo scans = `node --test scripts/*.test.mjs`). Preflight: `npm run doctor`. Reset: `npm run reset`. UI standard: `bash scripts/check-ui-standard.sh` (vendored `web/src/standalone-ui.css` must equal the canonical copy on GitHub origin/main of AI-DEMO-Standalone; re-vendor from origin, then `--pin`).
- Server: `snapshot.js` (the `env-map/1` validator: size cap, iterative depth check, fixed-shape walk, caps; problems never echo values), `roles.js` (role guess by name, roles file, `nameMatches`), `view.js` (the Today and After views, the what-if lists, links, matrix, summaries: pure), `source.js` (Mock file / Real file per request), `config.js` (`ENV_MAP_SNAPSHOT` from env or `~/Development/.env` / `STANDALONE_ENV`; Real refused off loopback and inside the repo; hints never echo the path), `app.js` (info, mode, reset, map), `safety.js`, `netguard.js`, `doctor.js`, `health.js` (`demo-health/1`).
- Web: `lib/layout.js` (pure: view -> ReactFlow nodes and edges; `chooseViewport` keeps the default zoom at 0.9 or more), `lib/route.js` (hash routes `#/diagram`, `#/map`, `/after`), `components/DiagramView.jsx` (ReactFlow, floating side panel, Reset layout), `MapView.jsx`, `ChangeLists.jsx`. React and ReactFlow are bundled by Vite: no CDN, no web font. Never use `innerHTML` or `dangerouslySetInnerHTML`; a repo test fails on it.
- Rules that bite: one port, 7805, `127.0.0.1:` only (a test pins it); `POST /api/mode` is exactly `{ source }` (409 when Real is not configured); compose has `restart: unless-stopped` (rule 21); the sample may carry only `.example`/`.invalid` hosts, no UUIDs, no e-mail, no @mentions; real data never enters the repo or logs; every name-derived role is shown as "by name, unverified"; the Docker image has no volumes and no `ENV_MAP_SNAPSHOT`.
- Theme tokens only (no colour literals in `app.css`), no purple, both themes, 375px; every control has a visible border (dark control contrast rule).
- `docs/shelf-entry.json` has no `catalogId` on purpose. It is NOT registered in demo-shelf-LAB `data/demos.json` yet; that needs the owner's go-ahead together with the repo.
- No AI attribution anywhere (owner rule 2026-11-07).
